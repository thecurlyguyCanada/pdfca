## How Do I Add Page Numbers to a PDF for Free?

Five steps. The numbering itself takes about a second even for a few hundred pages.

### Step 1: Add the PDF

Drop the file on **Drop your PDF here**, or click to choose it. The card shows the page count, with **Change file** if you picked the wrong one.

### Step 2: Choose the position and format

Under **Position**, tap one of the six spots on the small page diagram: **Top left**, **Top centre**, **Top right**, **Bottom left**, **Bottom centre** (the default) or **Bottom right**. Your choice is written next to the diagram.

Under **Format**, pick **1** (the default), **Page 1**, **Page 1 of 10** or **1 / 10**. The English page prints "Page 3 of 10"; the French page prints « Page 3 de 10 », so use the page in the language you need.

### Step 3: Set the first page and the start number

This is the step people get wrong. **First page to number** decides which page of the file gets the first number; pages before it get none. **Start at number** decides what that first number is. To skip a cover, set First page to number to 2 and leave Start at number at 1.

Before you run, a line spells out the result, for example "Pages 2 to 10 will be numbered 1 to 9." If that is not what you meant, change the fields now.

### Step 4: Adjust size, margin and colour, then check the preview

**Font size** is 11 points by default (6 to 72). **Margin** is **Normal** (½ inch) by default, with **Small** (¼ inch) and **Large** (¾ inch). **Colour** is **Black** or **Grey**. The preview shows the first numbered page with the number drawn to scale, so you can see whether it collides with a footer, a logo or a dark scanner border.

### Step 5: Click Add page numbers, then Download

A progress line counts the pages ("Page 12 of 40"), then the result card shows the file name, its size and how many pages were numbered, for example "9 pages numbered". Click **Download** to save `yourfile-numbered.pdf`. Your original is not changed.

## Which Format Should I Use?

On a 10-page file with the cover skipped (First page to number set to 2, Start at number 1):

| Format | Page 2 of the file shows | Last page shows | Good for |
|---|---|---|---|
| 1 | 1 | 9 | Reports, theses, most documents |
| Page 1 | Page 1 | Page 9 | Documents read on paper, where a bare number could be mistaken for something else |
| Page 1 of 10 | Page 1 of 9 | Page 9 of 9 | Contracts, leases and filings where a missing page must be obvious |
| 1 / 10 | 1 / 9 | 9 / 9 | Compact footers, slide handouts |

The total in "of N" and "/ N" is the last number printed: Start at number plus the pages from the first numbered page to the end, minus one. That is why skipping a cover on a 10-page file gives "of 9", and why the total stays right when you start at a number other than 1.

## How Do I Add Page Numbers but Skip the Cover?

Set **First page to number** to 2. The cover stays clean and the next page shows 1. The hint under the field says the same: pages before it get no number. To skip a cover and a table of contents, set it to 3.

If you would rather the cover count as page 1 without showing it, so the next page reads 2, set First page to number to 2 and Start at number to 2.

One thing to know: your PDF viewer's page box still counts the physical pages of the file. With the cover skipped, the page printed "1" is page 2 in the viewer. The tool does not rewrite the PDF's page labels.

## What Happens to the Rest of the File?

Almost nothing, which is the point. The tool opens your original PDF, adds one small text drawing to each numbered page and saves it. The existing page content is kept as it is, so:

- **Bookmarks stay.** A 400-page report in our tests kept all 41.
- **Fillable form fields stay.** An IRS W-4 kept all 54 fields, still fillable.
- **Images are not recompressed** and the text layer is untouched; the file grows by a few kilobytes.
- **Links and the document title stay.**

Numbers follow the page as you see it. On a page stored sideways with a rotation, the number is turned so it reads upright at the displayed top or bottom. On a cropped page, the margin is measured from the visible edge. Landscape pages are centred on their displayed width.

The number is real text in Helvetica, so it can be selected and searched. Only digits and the words "Page", "of" or « de » are printed, so there are no font or accent issues.

## How Do I Number a Tribunal or Court Package?

Tribunals and courts often ask for consecutively numbered pages, for example disclosure for the Immigration and Refugee Board, or a document brief for a landlord and tenant board or small claims court. Check the current practice notice for the exact rule. The order of operations matters:

1. Put every document in its final order with [Merge PDF](/en/merge-pdf), and fix any page order with [Organize PDF](/en/organize-pdf).
2. Number the merged file once. Numbering each document separately and then merging gives you several page 1s.
3. Choose **Page 1 of 10** or **1 / 10** so a missing page is obvious, and a corner the pages leave empty.
4. Compress last, if the upload portal has a size limit: [Compress PDF](/en/compress-pdf) at Good keeps the text.

If the package goes in several volumes, number volume 2 with Start at number set to the page after volume 1's last page.

## Use Cases by Situation

### A thesis or major research paper

Universities usually want the front matter unnumbered or in Roman numerals and the body starting at 1. Roman numerals are not available here, so either leave the front matter unnumbered with First page to number set to the first page of chapter 1, or number the front matter separately in your word processor before exporting.

### A lease or contract before signing

"Page 1 of 12" on every page makes it obvious if a page goes missing or gets swapped. Number the final version, then [Sign PDF](/en/sign-pdf). Fillable fields in a standard form lease stay fillable.

### Board or condo meeting packages

Agendas, minutes and reports merged into one package are easier to discuss when everyone can say "page 14". Number after merging so the numbers run through the whole package.

### Scanned documents for an IRCC or CRA upload

Numbering a scanned bundle adds only a few kilobytes, so it does not push a file over IRCC's usual 4 MB per document. On scans with a dark border, choose **Large** margin so the number sits on paper, not on the shadow.

## When Should You Not Use This Tool?

- **The PDF already has page numbers.** The tool cannot see them and will print over them if you choose the same spot. Pick another position or leave the file as it is.
- **You need Roman numerals, mirrored odd and even margins or a last page to number.** None is available. Number in your word processor before exporting to PDF.
- **You need Bates numbers or exhibit stamps** with a prefix such as ABC000123. Use dedicated legal software.
- **You want the viewer's page box to show your numbers.** The tool prints numbers on the page; it does not change the PDF's page labels.
- **The file is password-protected.** Remove the password in the app that created it, then number.
